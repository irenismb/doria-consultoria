# DORIA CONSULTORÍA S.A.S.

Sitio web corporativo de consultoría jurídica integral para el sector salud.

## Estructura

- Inicio
- Nosotros
- Servicios
- Metodología
- Contacto

El sitio es HTML, CSS y JavaScript estático. Puede abrirse localmente desde `index.html` y publicarse con GitHub Pages desde la raíz de la rama `main`.
